Highline Run for Windows. Plays with no internet. Built automatically from the latest version of the game.

**To play:** download `Highline-Run-Windows.zip`, right-click it and choose Extract All, open the folder, then double-click `Highline Run.exe`.

- The first time, Windows may say "Windows protected your PC" because the app isn't signed by a publisher. Click **More info**, then **Run anyway**.
- F11 or Alt+Enter switches full screen. Esc opens the menu, and **Controls** in the menu changes keys and controller buttons. Xbox, Switch and PlayStation controllers work over USB or Bluetooth.
- Progress is saved on the PC, separate from the browser version at https://mhelton1.github.io/Highline-Run/.

`offline.html` is the same game as a single file that you can open in any browser with no internet.
